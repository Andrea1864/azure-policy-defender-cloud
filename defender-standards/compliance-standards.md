# Compliance Standards — Microsoft Defender for Cloud
## TechPay Solutions

## Overview
TechPay has enabled 4 security standards in Microsoft 
Defender for Cloud to monitor compliance against key 
regulatory frameworks relevant to a Spanish fintech.

## Active Standards

### 1. Microsoft Cloud Security Benchmark
- **Recommendations**: 226
- **Purpose**: Microsoft's baseline security best practices
- **Relevance**: Foundation for all Azure security controls

### 2. Spain ENS (Esquema Nacional de Seguridad)
- **Recommendations**: 821
- **Purpose**: Spanish national security framework
- **Relevance**: Required for companies working with Spanish 
  public administration
- **Current compliance**: 25%

### 3. SWIFT CSP-CSCF
- **Recommendations**: 44
- **Purpose**: SWIFT Customer Security Controls Framework
- **Relevance**: Mandatory for payment and financial 
  messaging companies
- **Current compliance**: Under evaluation

### 4. EU 2022/2555 (NIS2 Directive)
- **Recommendations**: 181
- **Purpose**: EU Network and Information Security Directive
- **Relevance**: Mandatory for essential and important 
  entities in the EU
- **Current compliance**: 24%
